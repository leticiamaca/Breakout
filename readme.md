# 🧱 Breakout Game — Primeiros Passos com Excalibur.js

> Um exercício de aprendizado: nosso primeiro contato com desenvolvimento de jogos e TypeScript.

---

## 🎮 Sobre o Projeto

Este projeto é um jogo estilo **Breakout** — aquele clássico onde uma bolinha rebate e destrói blocos — desenvolvido como exercício exploratório para conhecer a biblioteca [Excalibur.js](https://excaliburjs.com/).

Não se trata de um produto final, mas sim de um **primeiro passo**: aprender na prática como funciona a lógica de um jogo, colisões, física simples e renderização, usando TypeScript como linguagem principal.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso |
|---|---|
| **TypeScript** | Linguagem principal |
| **Excalibur.js** | Engine de jogos 2D para web |
| **HTML / CSS** | Estrutura e estilo da página |
| **WAV (áudio)** | Som de colisão da bolinha com os blocos |

---

## 📚 O que Aprendemos

- Estrutura básica de uma game engine (cenas, atores, loop de jogo)
- Detecção e resposta a colisões
- Movimentação de sprites e física simples
- Integração de áudio em jogos web
- Primeiros passos com TypeScript em um contexto prático

---

## ▶️ Como Rodar

```bash
# Instale as dependências
npm install

# Inicie o projeto
npm run dev
```

Abra o navegador em `http://localhost:3000` (ou a porta configurada).

---

## ⚠️ Observação

Este é um projeto de **estudo e experimentação**. O código pode não seguir todas as boas práticas de produção — e tudo bem! O objetivo era aprender, explorar e se divertir no processo.
